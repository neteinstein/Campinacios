# Calhambeques

Acampamentos para animadores focados no serviço (Actualmente este escalão não tem acampamentos)

Realizou-se esporadicamente até 1998 e esteve desde aí sem se realizar, não sendo considerado uma prioridade do movimento.

Em 2011 foi feita uma proposta, por um grupo reunido por [Pedro Vicente](../Pessoas/P/Pedro%20Vicente.md), [Ana Paula Sampaio](../Pessoas/A/Ana%20Paula%20Sampaio.md), [António Queiroz Martins](../Pessoas/A/Ant%C3%B3nio%20Queiroz%20Martins.md), [Filipe Próspero](../Pessoas/F/Filipe%20Pr%C3%B3spero.md), [Gonçalo Vaz Pedro](../Pessoas/G/Gon%C3%A7alo%20Vaz%20Pedro.md), [Maria Cortês Ferreira](../Pessoas/M/Maria%20Cort%C3%AAs%20Ferreira.md), [Pedro Pinheiro](../Pessoas/P/Pedro%20Pinheiro.md), [Teresa Pinheiro](../Pessoas/T/Teresa%20Santos.md), [Renato Costa](../Pessoas/R/Renato%20Costa.md) e [António Sant'Ana](../Pessoas/A/Ant%C3%B3nio%20Sant%27Ana.md). Foi proposto um acampamento/acantonamento de serviço sem participantes (alunos dos colégios), só com animadores, e a [Direcção Nacional](Direc%C3%A7%C3%A3o%20Nacional.md) aprovou-o.

Retomou-se assim em 2011 o escalão, com o "primeiro" campo a chamar-se [Esperança](../Acampamentos/2011/Esperan%C3%A7a.md), como experiência para perceber a viabilidade futura.
