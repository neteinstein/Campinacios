# Rockstock

O Rockstock é uma actividade nacional para [Lambretas](../Categorias/Lambretas.md). Tradicionalmente na pausa do Carnaval, os Lambretas vão para uma aldeia ou vila do interior de Portugal para servir a comunidade local de diversas formas. Na última noite, oferece-se à comunidade um serão musical.
