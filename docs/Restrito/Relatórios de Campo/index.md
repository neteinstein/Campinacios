# Relatórios de Campo

Relatórios escritos pelas direcções de campo depois de cada acampamento, para
os directores que viessem a seguir: preparação, plano de campo, avaliações,
contas e sugestões. São páginas restritas: o texto está cifrado e só se lê com
a palavra-passe. Os contactos e os dados pessoais de participantes e
animadores que os relatórios originais tinham ficaram de fora; as fichas de
jogo estão no [Caderno de Jogos](../../Movimento/Caderno%20de%20Jogos.md) e as
músicas no [Cantinácio](../../Movimento/Cantin%C3%A1cio.md).
