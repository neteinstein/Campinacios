# Francisco Costa Macedo

Francisco Costa Macedo foi um animador do CSJB. Foi também jesuíta. É ex-aluno do [CSJB](../../Movimento/CSJB.md).

## Família

É marido de [Concha Macedo](../C/Concha%20L%C3%ADbano%20Monteiro.md)

### Cargos

- 1991 Coordenador do [CIFA I](../../Acampamentos/1991/CIFA%20I.md)

    - 1991 [Cagácios](../../Acampamentos/1991/Cag%C3%A1cios.md) - [Director](../../Cargos/Director.md)
