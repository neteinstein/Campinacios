# CACAINA

CACAINA é um acrónimo para Conferência de Animação dos CAmpinácios do Instituto Nun'Álvres (Colégio das Caldinhas). Esta acção de formação decorreu nos dias 25, 26 e 27 de Março de 1994 em Esposende.
