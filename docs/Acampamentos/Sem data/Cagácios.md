# Cagácios

CAGÁCios é um acrónimo para Campo de Auto-Gestão para Animadores dos Campinácios. Foi uma acção de formação/passagem de ano que decorreu de 30 de Dezembro de 1991 a 3 de Janeiro de 1992 na Quinta da Cardiga (Entroncamento).
