# FINO 99

O FINO 99 foi uma acção de formação de novos animadores organizada pela [Direcção Local do Colégio São João de Brito](../../Categorias/Direc%C3%A7%C3%A3o%20Local%20do%20CSJB.md) em 26, 27 e 28 de Fevereiro de 1999 no Baleal. FINO é um acrónimo para Formação Intensiva de Novos Obreiros.
