# Salvo Sejas

**Salvo Sejas** foi um acampamento de [Lambretas](../../Categorias/Lambretas.md) realizado em 2017, de 17 a 26 de agosto, em Serpins. O tema do ano foi *Guarda tudo no teu coração*.
