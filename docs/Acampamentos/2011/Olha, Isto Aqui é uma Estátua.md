# Olha, Isto Aqui é uma Estátua

**Olha, Isto Aqui é uma Estátua** foi um acampamento de [Triciclos](../../Categorias/Triciclos.md) realizado de 23 de Agosto a 1 de Setembro de 2011. O tema do ano foi *Sobre esta pedra*.
