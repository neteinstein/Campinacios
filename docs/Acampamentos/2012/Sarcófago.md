# Sarcófago

**Sarcófago** foi um acampamento de [Triciclos](../../Categorias/Triciclos.md) realizado em 2012 em [Digueifel (Arganil)](../../Restrito/Locais%20de%20Acampamento/Digueifel%20%28Arganil%29.md). O tema do ano foi *Ainda te falta uma coisa*.

### Animadores
